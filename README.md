# Python Keylogger

A basic Python Keylogger built using the **pynput** library to demonstrate how keyboard event capturing and input logging work at the system level.
This project was developed for educational and cybersecurity awareness purposes to understand monitoring techniques, keyboard listeners, and event handling in Python.

**This project is strictly for ethical learning and authorized environments only.**

## Features

Captures keyboard input events

Logs alphanumeric and special keys

Real-time key press detection

Saves captured keystrokes into a log file

Stops execution using the ESC key

## Cybersecurity Concepts Demonstrated

Keyboard Event Monitoring

Input Capture Techniques

System-Level Event Listeners

Logging & Monitoring

Ethical Security Awareness

## Tech Stack

Language: Python

Library Used: pynput

## Installation & Setup
1. Clone the Repository
```bash   
git clone https://github.com/your-username/Python-Keylogger.git
cd Python-Keylogger
```
2. Install Dependencies
```bash
pip install pynput
```

3. Run the Script
```bash
python keylogger.py
```

## How to Stop

Press:
```bash
ESC
```

to terminate the listener safely.
